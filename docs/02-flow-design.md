# 02. 사용 흐름·디자인

선택 시안: **B "사이드바 관제형" · 명랑**

## 1. 핵심 시나리오

### S1. 아침 스탠드업에서 내 카드 옮기기
**언제**: 매일 아침 스탠드업 직전 1분. 팀원이 각자 자기 PC에서 연다
**흐름**
1. 로그인되어 있으면 마지막으로 본 팀 보드가 바로 열린다
2. 사이드바의 "누가 얼마나?"에서 자기 이름을 눌러 자기 카드만 보이게 한다
3. 어제 끝낸 카드를 "완료"로 드래그하면 자기 부하 숫자가 3에서 2로 줄어든다
4. "할 일" 컬럼 하단의 `+ 추가`에서 제목을 입력하고 Enter로 카드를 만든다. 필터가 켜져 있으면 그 사람이 담당자로 자동 지정된다 (가정)

**인사이트**: 카드는 모달 없이 컬럼 안에서 바로 추가한다. 마지막으로 본 팀은 localStorage에 기억한다.

### S2. 주 1회 팀장의 업무 재배분
**언제**: 금요일 오후, 팀장이 다음 주 업무를 나누기 전
**흐름**
1. 사이드바에서 민수 6, 지은 1처럼 쏠림이 보인다. 과부하 기준(가정: 5)을 넘은 사람은 ⚠와 경고색으로 표시된다
2. 민수를 눌러 그의 카드만 띄운다
3. 카드를 열어 담당자를 지은으로 바꾸면 두 사람의 숫자와 막대가 즉시 갱신된다
4. 민수를 다시 눌러 필터를 풀고 보드 전체를 확인한다

**인사이트**: 카드 상세에서 담당자는 팀원 색 칩을 한 번 클릭해서 바꾼다. 부하는 숫자와 막대 길이로 함께 보여준다.

## 2. 화면 구조

```
[로그인/가입] ──로그인──▶ [보드] ◀─────────────┐
                           │ 사이드바에서 팀 전환 │
                           ├─▶ [카드 상세 모달] ─┤  제목·설명·담당자·삭제
                           └─▶ [팀 설정 모달] ───┘  팀 이름 변경, 팀 삭제
```
- 화면은 로그인과 보드 2개이고, 나머지는 보드 위 모달로 연다
- 팀 추가(`+ 새 팀`)와 팀원 추가(`+ 팀원`)는 사이드바 안에서 바로 입력한다
- 컬럼 이름은 헤더를 더블클릭해서 바꾸고, 삭제는 헤더의 ⋯ 메뉴에서 한다

## 3. 확정 디자인

**철학**: 팀과 사람이 왼쪽 축에 있고, 보드는 그 사람들이 하는 일로 보인다.

### 시각 규칙
| 요소 | 규칙 |
|---|---|
| 배경 | 크림색 (`#FBF8F3` 근처) |
| 컬럼 | 컬럼마다 다른 파스텔 배경, 둥근 모서리 12px |
| 카드 | 흰색, 둥근 모서리 10px, 옅은 그림자. 왼쪽 4px 띠는 담당자 색 (미배정은 회색) |
| 팀원 색 | 미리 정한 8색 팔레트에서 등록 순서대로 배정 |
| 부하 막대 | 가장 큰 값을 100%로 놓고 길이 비례. 과부하(> 5)는 주황 막대와 ⚠ |
| 필터 상태 | 선택된 팀원 행은 배경을 강조하고, 다른 사람의 카드는 숨긴다 |
| 사이드바 | 폭 220px. 768px 미만에서는 접히고 ☰ 버튼으로 연다 |
| 글꼴 | Pretendard, 기본 14px |

## 가정 목록 (Phase 2 추가분)
- 과부하 기준은 진행 중 카드 5장 초과로 고정. 팀마다 바꾸는 설정은 넣지 않음
- 필터가 켜진 상태에서 카드를 추가하면 그 팀원이 담당자로 자동 지정됨
- 마지막으로 본 팀 ID는 브라우저 localStorage에 저장 (데이터 자체는 Supabase)
- 미배정 카드도 부하 목록 맨 아래에 한 줄로 표시하고, 눌러서 필터할 수 있음
